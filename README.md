### Project Description
A Java-based console application simulating the NUST Student Service Centre. This project features custom implementations of Queues, Singly Linked Lists, Stacks, Arrays, and comparative sorting algorithms (Selection, Insertion, Merge, and Quick Sort) without relying on built-in collection shortcuts.

### Instructions for Running the Program
1. Ensure you have the Java Development Kit (JDK 8 or newer) installed.
2. Clone or download this repository.
3. Compile all `.java` source files using your preferred IDE (e.g., IntelliJ, Eclipse) or command line:
   ```bash
